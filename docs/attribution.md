## Adaptation

The adaptation adds Godot Web export, the iDosGames host, Solana signed-challenge
login, a holder-bonus UI and the Godot/host bridge for delivering one tool per run.
The shop-button icon was supplied by the project owner.

README organization was inspired by
https://github.com/Marakaya/colosseum_example. The example's project-specific
technical claims, team details, program code and license were not copied.
