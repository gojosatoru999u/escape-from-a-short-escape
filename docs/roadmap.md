# Roadmap

## Implemented

- Browser adaptation and iDosGames hosting of the existing Godot island game.
- Free entry through iDosGames or Solana wallet authentication.
- Holder bonus dialog next to the resources, using the supplied pixel shop icon.
- One free tool per run when the confirmed wallet's main account holds 5,000 ESCAPE.
- Read-only Solana checks, precise integer amounts, fresh claim validation.
- Godot tool delivery and duplicate-choice protection.

## Next

1. Complete wallet signature/linking tests with real Phantom and Solflare wallets.
2. Test small screens and improve mobile game controls.
3. Record a gameplay walkthrough showing free entry and the optional holder bonus.
4. Gather gameplay feedback before expanding content.

## Conditional future work

Add a verifier service only if future features introduce valuable transferable
rewards. Purchases and automatic token buybacks were removed at the owner's
request and are not part of the current product.
