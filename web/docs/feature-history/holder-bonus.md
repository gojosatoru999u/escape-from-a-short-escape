# Holder bonus

The owner chose free gameplay and replaced paid tools with a holder bonus.
The three original tools are Pickaxe, Club and Sword; there is no shovel.
One bonus is available per run with 5,000 ESCAPE on the confirmed wallet's
main associated token account. Tokens are not spent and items remain craftable.

The free iDosGames plan blocks outgoing CloudCode RPC requests, so this
single-player bonus uses a browser read. Do not treat it as an authoritative
financial entitlement. See the root `docs/architecture.md` for trust boundaries,
`docs/deployment.md` for platform settings and `docs/attribution.md` for origins.
